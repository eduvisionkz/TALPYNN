# Talpyn: аудит и изменения к 27 сентября 2026

## Что изучено

Исходники React/Vite, маршруты ученика, учителя и администратора, конструктор уроков, обработчики ответов, библиотека учебного содержания, материалы, схемы Supabase и миграции `0001`–`0040`. В каталоге 113 тем: 112 тем представлены в исходных модулях, одна флагманская тема находится в SQL. Для всех предусмотрено по десять заданий. Исходный отчёт о тематических заданиях: `REVIEW_FINDINGS_2026-09-27.md`.

## Локальные проверки

- `npm run lint` — успешно.
- `npm run build` (TypeScript и Vite) — успешно.
- `node --import tsx scripts/auditTaskCounts.ts` — 112 исходных тем имеют по 10 заданий; ещё одна тема проверяется отдельно в SQL.
- `node --import tsx scripts/auditTaskSemantics.ts` — 325 структурных проверок интерактивов и 909 вычисляемых числовых равенств без выявленного несоответствия.
- `node --import tsx scripts/checkLessonContent.ts` — 112 модулей согласованы с каталогом.
- 1773 явных литерала `::jsonb` всех 40 миграций разбираются JSON-парсером. Это не проверка выполнения SQL в PostgreSQL.
- Локальный `vite preview` запустился, но контейнер не разрешил подключиться к `127.0.0.1:4173` из второго процесса. Поэтому HTTP и браузерная проверка не подтверждены.

## Функции, которые остаются незавершёнными или требуют работы

1. Нет автоматического преобразования PDF/DOCX в редактируемые задания. Файлы сейчас прикрепляются как материалы.
2. Нет автосохранения, копирования темы, полноценной истории изменений и восстановления версий. Задания в конструкторе можно менять местами кнопками; свободное перетаскивание внутри конструктора не подтверждено.
3. Нет модели принадлежности ученика к классу конкретного учителя. Поэтому миграция `0035` ограничивает учителю доступ к результатам собственных тем, а не ко всем темам учеников его класса. Для классной аналитики потребуется явное назначение класса и согласованная RLS-модель.
4. Результаты по 24 прежним сопоставлениям из `REVIEW_FINDINGS_2026-09-27.md` требуют оценки учителя. Автоматические проверки не подтверждают педагогическое качество всех 1130 заданий.
5. Расположение оригинального Талпына на всех страницах и мобильной версии требует визуальной проверки. В шапке всех маршрутов и интерактивах используется исходный PNG; разнообразие поз пока ограничено тремя имеющимися изображениями.
6. Бакет материалов публичный. Перед хранением непубличных материалов детей нужен отдельный механизм приватного доступа и выдачи временных ссылок.
