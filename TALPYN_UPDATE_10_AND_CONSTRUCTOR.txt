TALPYN: ЗАДАНИЕ №10 И КОНСТРУКТОР УЧИТЕЛЯ

1. Загрузите в GitHub четыре файла из папки src, сохранив их пути.
2. Дождитесь автоматического деплоя Vercel.
3. В Supabase откройте SQL Editor.
4. Откройте supabase/migrations/0019_teacher_constructor_access.sql,
   скопируйте весь текст, вставьте в SQL Editor и нажмите Run.
5. Войдите на сайт под учителем и откройте «Мұғалім кабинеті».

После обновления:
- условие задания №10 показывается перед полем ответа;
- «Жаңа тақырып» создаёт новую тему;
- «Дайын тақырыпты өңдеу» открывает каталог системных тем;
- «Конструкторда өңдеу» позволяет менять этапы и задания;
- «PDF / инфографика қосу» загружает PDF, изображения и видео;
- в «Бекіт» можно выбрать шаблон интерактивного задания.

Важно: SQL разрешает учителям редактировать общие системные темы, но не
разрешает им удалять эти темы. Темы, созданные другим учителем, остаются
недоступными для редактирования.
